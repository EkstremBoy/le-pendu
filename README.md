# Le Pendu

Jeu du pendu bilingue (FR / EN).

Trois longueurs — Court, Moyen, Long — neuf catégories, et un personnage à sauver avant la dernière lettre.

## Local

```bash
npm install
npm run dev
```

## Build

Le fond aquarelle `public/art/hills.jpg` est décodé depuis `hills.jpg.b64` au build (`scripts/decode-art.mjs`).
